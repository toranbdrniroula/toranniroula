# Figures and interactive media

Article settings are the JSON block between `---` lines at the top of the
Markdown file. All paths in settings start at the repository root, without `/`.
Paths inside article HTML should start with `/`, as in the examples below.

## Hero and supporting images

Work settings: `"media_type": "image"`, `"media_src": "assets/media/hero.png"`.
For a carousel, use `"media_type": "carousel"` and
`"hero_slides": [{"src":"assets/media/one.png","caption":"What this shows"}]`.
Video uses `"media_type": "video"`, an MP4 `media_src`, and the thumbnail as poster.
Writing settings optionally accept `"hero": "assets/media/hero.gif"` and `"hero_alt"`.
`"supporting_media": ["assets/media/one.png"]` adds a supporting gallery to work pages.

## Article figure

```html
<img src="/assets/media/figure.png" alt="Describe the scientific result">
<span class="md-caption">Explain the figure.</span>
```

Images are centered and can be enlarged. Original-image links work without
JavaScript. No manual image dimensions or lightbox code is needed.

## Models and fields

```html
<stl-reader href="/assets/media/model.stl" poster="/assets/media/model-preview.png" label="Airframe geometry" height="480"></stl-reader>
<vtk-reader href="/content/data/field.vtp" poster="/assets/media/field-preview.png" label="Mach number field" field="user-defined" colormap="user-defined" initial-colormap="rainbow" height="540"></vtk-reader>
```

Use a poster image for a new dataset. The static reference is shown until the
interactive viewer successfully renders, and returns if it fails. `rainbow`
means Rainbow Desaturated; the picker remains available. Clipping and threshold
controls are enabled with `clipping="true"` and `threshold="true"`.

## Scroll tour

```html
<scroll-reveal-viewer mode="model" poster="/assets/media/aircraft.png" label="Aircraft tour">
  <reveal-frame href="/assets/media/aircraft.glb" azimuth="25" elevation="16" distance="2.4" target="0,0,0">
    <h4>Airframe</h4><p>Explain the geometry.</p>
  </reveal-frame>
  <reveal-frame azimuth="80" elevation="10" distance="1.0" target="0.3,0,0.6">
    <h4>Wing</h4><p>Explain this detail.</p>
  </reveal-frame>
</scroll-reveal-viewer>
```

The model is normalized to a longest dimension of 1.6 units. Targets are
fractions of its half-extents. Distances adapt to narrow screens; close-up
waypoints intentionally inspect details. Viewer captions stay out of contents.

## Video and charts

```html
<video-embed src="/assets/media/clip.mp4" poster="/assets/media/clip.png" label="Describe the clip" controls="true"></video-embed>
<plotly-chart href="/content/data/results.json" type="scatter" title="Your chart title" height="380"></plotly-chart>
```

Chart source JSON contains `data` traces with matching `x` and `y` arrays and
optional `layout.xaxis.title` / `layout.yaxis.title`. Complete CSV downloads are
generated by the build; do not commit generated CSV or manually add download links.
Math uses `$...$` or `$$...$$`, and code uses fenced Markdown blocks.
