## Interpretation notes

The cylinder page distinguishes the archived static-pressure-based coefficient (1.62037) from the post-shock stagnation-pressure coefficient (approximately 1.8181). Archived numerical data and scripts remain unchanged; only the chart title punctuation was updated.

The intake page distinguishes the reported nominal recovery 0.500 from the script output 0.50425, and the geometry table cowl angle 26.15 degrees from the script output 25.8538 degrees. The design uses two sequential oblique shocks in a single-ramp intake. No new CFD results have been invented.
